# AI Engineering Learning Repository

## Overview

This repository contains my early-stage explorations in AI Engineering, focusing on building and understanding fundamental components of LLM-based systems.

It includes experiments around conversational systems, tool usage, streaming responses, and basic agentic workflows using Python.

The goal of this repository is to develop a strong practical understanding of how modern AI applications are structured and how large language models can be integrated into real-world systems.

---

## Contents

This repository includes implementations and experiments related to:

- Basic chatbot implementations
- Multi-turn conversational systems
- Streaming response generation
- Tool calling and tool integration with LLMs
- Simple AI agent prototypes
- Experiments with LLM-based decision making (e.g., tool selection)

---

## Repository Structure

The repository is currently in an early development stage and does not follow a strict architectural pattern.

Each Python file represents an independent experiment or concept.

---

## Key Concepts Explored

- Large Language Model interaction patterns
- Prompt-based tool usage
- Streaming outputs from LLM systems
- Multi-turn conversation handling
- Basic agent design and orchestration
- Manual vs LLM-driven tool selection strategies

---

## Purpose

The purpose of this repository is to:

- Understand how LLM-powered applications work internally
- Experiment with different AI system designs
- Build intuition for agentic workflows
- Practice integrating tools with language models
- Develop foundational AI engineering skills
