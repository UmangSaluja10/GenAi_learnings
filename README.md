# 🚀 AI Engineering Learning Repository

## 📌 Overview

This repository documents my **hands-on journey into AI Engineering**, where I follow structured tutorials and rebuild systems from scratch to deeply understand how modern LLM-powered applications work.

Instead of passively watching, I:

- Re-implement everything in Python  
- Break down each concept  
- Experiment with variations  
- Build intuition for real-world AI systems  

The learning path is based on a **100-day AI Engineering roadmap**, progressing from fundamentals to advanced agent systems.

---

## 🎯 Learning Approach

This repository is built on a **learn-by-doing methodology**:

1. Follow a concept/tutorial  
2. Rebuild the implementation independently  
3. Analyze how and why it works  
4. Modify and experiment with variations  
5. Document key learnings through code
